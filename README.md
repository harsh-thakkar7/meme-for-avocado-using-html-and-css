# Meme for Avocado

A motivational meme-style web page — "That Special Moment: when you find the perfect avocado at the supermarket".

## Structure

- `index.html` — the meme poster markup
- `style.css` — styling (black background, Libre Baskerville font, white-bordered image)
- `assets/images/daenerys.jpeg` — the meme image

Inspired by the classic "Motivation Meme" exercise. The page uses a full-width centered poster layout with uppercase heading text.

## Viewing

Open `index.html` in any web browser.
